# 참가자 경기 승 승률 점유율 포인트
아직 시즌 기록이 없습니다 밸런서에서 내전을 정산하고 시즌에 반영을 누르면 랭킹이 만들어집니다.

코인 규칙: 내전 참여 경기 × 150P + 승리 × 70P. #불레디티어인증에서 티어를 인증하면 프로필에 티어 배지가 표시됩니다. 시즌 초기화 시 모든 기록과 코인이 삭제됩니다.

🎁

교환 신청 후 운영진이 확인하면 지급됩니다. 신청 시점에 코인이 차감되며, 취소하면 다시 돌려받습니다. 재고는 신청 기준으로 자동 차감됩니다.

디스코드 봇 연동 설정

교환 신청·랭킹 공지를 보낼 채널의 웹훅입니다.

봇 서버가 준비되면 입력하세요. 아래 JSON 스키마를 그대로 조회하도록 만들면 됩니다.

준비된 봇 명령 예시: /포인트 · /랭킹 · /상점 · /교환. 자세한 스키마는 오른쪽 JSON을 참고하세요.

봇 API 계약 (제안)

메서드경로설명
GET/points?name=닉네임해당 참가자의 포인트·경기·승리·승률 조회
GET/leaderboard?limit=10시즌 랭킹 상위 N명
GET/shop상품 목록과 재고
POST/redeem교환 신청 (닉네임, 상품 ID) → 포인트 차감
POST/settle내전 정산 결과 적립 (밸런서 JSON 그대로)

이 사이트는 정적 페이지라 데이터가 브라우저에만 저장됩니다. 봇과 실시간으로 공유하려면 위 스키마대로 봇 서버를 붙이고, 이 페이지의 JSON을 전송하거나 봇 DB를 조회하도록 연결하세요.
